One ref without a file retains the original single operation, confirm text, DTO and exit behavior. Other calls use a distinct typed bulk mutation, so ordinary documents never select the new field. Bulk preview is one dryRun=true call. --dry-run prints it. Otherwise successful per-entry revisions must agree; a mismatch refuses exit5 before apply. All-failed preview prints and exits1 without a real call. Replacement roles are aggregated into one confirmation. Keep every target/index, no filtering; all-failed and dry-run still never apply. Stdin-file input needs --yes when confirmation is required. Real apply sends the preview revision, never retries. Reports preserve server echoes in JSON and original refs in text, validate positions/shape/counts, and print all per-entry failures before silent exit1. Server text uses SafeCell; unknown error codes are rendered generically. Skips are success.

Whole-call failures use existing MapError plus caller-input exit2 for BULK_TARGETS_TOO_MANY; the provider message names cap/count. The server owns access, cap and deduplication. A partial result is not rolled back; retry failed targets after checking their errors, excluding DUPLICATE_TARGET positions already attempted earlier; never rerun the whole file. A transport/protocol failure after apply may leave writes: the runtime warns some memories may already have changed and to verify configs before retrying, with no automatic compensation; documented whole-call refusals retain their original exits and do not get an uncertainty warning.
